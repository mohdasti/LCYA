## **Individual Differences**

Pearson correlations revealed no significant associations between difference scores for each task condition and the AUC metrics.

### Total AUC × Accuracy

Total AUC did not significantly relate to Physical Effort difference scores (High minus Low) for accuracy for the CDT (*r* = −.09, 95% CI [−.39, .23], *p* = .59, *n* = 39), ADT (*r* = −.06, 95% CI [−.37, .26], *p* = .70, *n* = 39), and VDT (*r* = −.16, 95% CI [−.46, .17], *p* = .35, *n* = 37).

Total AUC did not significantly relate to Task Difficulty difference scores (Hard minus Easy) for accuracy for the ADT (*r* = .19, 95% CI [−.13, .48], *p* = .25, *n* = 39) or VDT (*r* = .07, 95% CI [−.26, .39], *p* = .66, *n* = 37).

### Total AUC × Correct RT

Total AUC did not significantly relate to Physical Effort difference scores (High minus Low) for correct RT for the CDT (*r* = −.00, 95% CI [−.32, .31], *p* = .98, *n* = 39), ADT (*r* = −.07, 95% CI [−.38, .25], *p* = .66, *n* = 39), and VDT (*r* = −.08, 95% CI [−.39, .25], *p* = .66, *n* = 37).

Total AUC did not significantly relate to Task Difficulty difference scores (Hard minus Easy) for correct RT for the ADT (*r* = .25, 95% CI [−.09, .54], *p* = .14, *n* = 35) or VDT (*r* = .04, 95% CI [−.29, .36], *p* = .82, *n* = 37).

### Cognitive AUC × Accuracy

Cognitive AUC did not significantly relate to Physical Effort difference scores (High minus Low) for accuracy for the ADT (*r* = −.07, 95% CI [−.38, .25], *p* = .68, *n* = 39) or VDT (*r* = −.08, 95% CI [−.40, .25], *p* = .63, *n* = 37).

Cognitive AUC did not significantly relate to Task Difficulty difference scores (Hard minus Easy) for accuracy for the ADT (*r* = .13, 95% CI [−.19, .43], *p* = .43, *n* = 39) or VDT (*r* = −.07, 95% CI [−.39, .26], *p* = .67, *n* = 37).

### Cognitive AUC × Correct RT

Cognitive AUC did not significantly relate to Physical Effort difference scores (High minus Low) for correct RT for the ADT (*r* = −.12, 95% CI [−.42, .20], *p* = .46, *n* = 39) or VDT (*r* = −.06, 95% CI [−.38, .27], *p* = .71, *n* = 37).

Cognitive AUC did not significantly relate to Task Difficulty difference scores (Hard minus Easy) for correct RT for the ADT (*r* = .28, 95% CI [−.06, .56], *p* = .10, *n* = 35) or VDT (*r* = .03, 95% CI [−.30, .35], *p* = .88, *n* = 37).

**Note:** All analyses used the subject means approach, where difference scores were averaged to one value per subject before correlation. CDT was analyzed for Physical Effort effects only; Cognitive AUC was not analyzed for CDT per analytical recommendations.
