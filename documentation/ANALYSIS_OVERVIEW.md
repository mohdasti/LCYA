# Analysis Overview

## Study Description

The LCYA study investigates perceptual discrimination abilities across multiple sensory modalities and their relationship to memory and confidence measures in young adults.

## Tasks

### 1. Auditory Discrimination Task (ADT)
- **Purpose**: Measure frequency discrimination sensitivity
- **Stimuli**: Pure tones with varying frequency differences
- **Response**: Same/Different judgments with confidence ratings
- **Key Measures**: Proportion of "Different" responses, reaction time, confidence

### 2. Visual Discrimination Task (VDT)
- **Purpose**: Measure contrast discrimination sensitivity
- **Stimuli**: Visual patterns with varying contrast levels
- **Response**: Same/Different judgments with confidence ratings
- **Key Measures**: Proportion of "Different" responses, reaction time, confidence

### 3. Color Discrimination Task (CDT)
- **Purpose**: Measure color discrimination sensitivity
- **Stimuli**: Color patches with varying hue differences
- **Response**: Same/Different judgments with confidence ratings
- **Key Measures**: Proportion of "Different" responses, reaction time, confidence

### 4. Memory Similarity Task (MST)
- **Purpose**: Measure memory-based similarity judgments
- **Stimuli**: Images with varying similarity to studied items
- **Response**: Old/Similar/New judgments with confidence ratings
- **Key Measures**: Proportion of each response type, reaction time, confidence

## Analysis Pipeline

### Data Processing
1. Load trial-level behavioral data
2. Filter valid responses and exclude problematic participants
3. Calculate summary statistics by condition and stimulus level
4. Compute within-subject standard errors for error bars

### Statistical Analysis
1. Descriptive statistics for each task
2. Psychometric function fitting
3. Reaction time analysis
4. Confidence rating analysis
5. Grip strength interaction analysis

### Visualization
1. Proportion of responses by stimulus level
2. Reaction time by condition and stimulus level
3. Confidence ratings by condition and stimulus level
4. Distribution plots with split-violin plots
5. Combined multi-panel figures

## Technical Notes

- All error bars represent within-subject standard error of the mean (SEM)

- Confidence ratings are on a 1-4 scale
- Grip strength is analyzed as a binary factor (high/low) based on median split
